햇살딸기농장 반응형 웹사이트
============================

[실행]
1. ZIP 압축을 풉니다.
2. index.html을 크롬에서 실행합니다.
3. 메인 페이지의 생딸기 상품 카드를 클릭하면 product.html 상세페이지로 이동합니다.

[파일 구성]
- index.html : 메인 원페이지
- product.html : 생딸기 상품 상세페이지
- css/style.css : 메인 페이지 스타일 및 반응형 스타일
- js/main.js : 모바일 메뉴, 체험 예약 팝업, 예약 폼 동작
- assets/ : 실제 이미지 파일
  - strawberry-detail.jpg : 이번에 첨부한 세로형 상품 상세페이지 디자인 이미지

[상세페이지]
- 상품 요약 및 대표 상품 사진
- 첨부 상세페이지 이미지 전체 삽입
- 구매 문의 팝업
- 모바일 화면 대응

[주의]
- 상품 가격, 주소, 연락처는 실습용 임의 정보입니다.
- 예약 및 구매 문의는 화면 동작 예시이며 실제 데이터가 저장되거나 전송되지 않습니다.
- Google Fonts는 인터넷 연결이 필요합니다.
